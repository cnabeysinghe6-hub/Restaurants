CEYLON SPICE HOUSE — MULTI-PAGE RESTAURANT DEMO

Pages:
- index.html (Home)

How to preview:
1. Extract this ZIP file.
2. Open the ceylon-spice-house folder.
3. Open index.html in Chrome. Use the top navigation to visit the other pages.

All pages share assets/style.css and assets/main.js.
This is a demo. Replace sample contact details, menu prices, gallery images and form handling before using it for a real client.
Internet is required for Google Fonts and remote Unsplash images.
